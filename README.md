# Credit Card Fraud Analysis

## Project Overview
This project analyzes credit card transactions to identify fraudulent activities and understand customer spending patterns.

## Career Objective
To apply data analytics techniques to solve real-world banking and financial problems.

## Tools & Technologies
- Microsoft Excel
- SQL
- Power BI
- Data Cleaning
- Data Visualization

## Project Objectives
1. Analyze total transaction amount.
2. Identify fraudulent transactions.
3. Calculate fraud percentage.
4. Analyze spending by category.
5. Identify high-risk transaction patterns.

## Key Performance Indicators
- Total Transactions
- Total Transaction Amount
- Fraudulent Transactions
- Fraud Rate %
- Average Transaction Value

## Project Workflow
1. Data Collection
2. Data Cleaning using Excel
3. Data Analysis using SQL
4. Dashboard Development using Power BI
5. Business Insights and Recommendations
